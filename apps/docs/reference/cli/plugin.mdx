### bolt plugin new

Scaffold a new bolt plugin

```bash
bolt plugin new <name> [options]
```

| Argument | Type       | Alias | Required | Default | Description                                                |
| -------- | ---------- | ----- | -------- | ------- | ---------------------------------------------------------- |
| `name`   | positional |       | yes      |         | Plugin name (lowercase alphanumeric, hyphens, underscores) |
| `--user` | boolean    |       |          | `false` | Create in user scope (~/.bolt/plugins/)                    |
