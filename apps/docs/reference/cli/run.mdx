Run tasks (in typed order) or a flow defined in bolt.yaml

```bash
bolt run [options]
```

| Argument     | Type    | Alias | Required | Default | Description                                                                                          |
| ------------ | ------- | ----- | -------- | ------- | ---------------------------------------------------------------------------------------------------- |
| `--dry-run`  | boolean |       |          | `false` | Show what would run without running anything: no commands, plugins, hooks, or file writes            |
| `--simulate` | boolean |       |          | `false` | Load plugins and run hooks and handlers in dry-run mode; writes a log file and may have side effects |

Unknown or reserved flags exit `2` before the command runs. See [Invalid flags](/cli#invalid-flags).
