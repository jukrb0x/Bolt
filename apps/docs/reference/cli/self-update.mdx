Update a script-installed bolt to a GitHub release

```bash
bolt self-update [tag] [options]
```

| Argument    | Type       | Alias | Required | Default | Description                                                    |
| ----------- | ---------- | ----- | -------- | ------- | -------------------------------------------------------------- |
| `--force`   | boolean    |       |          | `false` | Re-download even if already up to date                         |
| `tag`       | positional |       |          |         | Install this version instead of the latest, for example v2.1.0 |
| `--version` | string     |       |          |         | Same as the positional version, for example 2.1.0              |

Unknown or reserved flags exit `2` before the command runs. See [Invalid flags](/cli#invalid-flags).
