### bolt env ensure

Fill required environment gaps. Dry-run prints a plan and plan_hash. Execute needs that hash and --confirmed-by-user

```bash
bolt env ensure [options]
```

| Argument              | Type    | Alias | Required | Default | Description                                                          |
| --------------------- | ------- | ----- | -------- | ------- | -------------------------------------------------------------------- |
| `--dry-run`           | boolean |       |          | `false` | Print the fill-gaps plan and plan_hash. Does not change this machine |
| `--execute`           | boolean |       |          | `false` | Apply a dry-run plan. Requires --plan and --confirmed-by-user        |
| `--plan`              | string  |       |          |         | plan_hash from bolt env ensure --dry-run                             |
| `--confirmed-by-user` | boolean |       |          | `false` | User approved this plan. Required with --execute                     |
| `--json`              | boolean |       |          | `false` | Print one bolt.env.ensure/v1 JSON document on stdout                 |
| `--manifest`          | string  |       |          |         | External manifest path relative to the project root                  |
