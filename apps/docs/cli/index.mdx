Bolt provides a comprehensive CLI for Unreal Engine workflow automation.

## Command Overview

| Command                                | Description                                  |
| -------------------------------------- | -------------------------------------------- |
| [`bolt run`](/cli/run)                 | Run tasks (in typed order) or a flow         |
| [`bolt list`](/cli/list)               | List all tasks and flows                     |
| [`bolt info`](/cli/info)               | Show project and VCS configuration           |
| [`bolt check`](/cli/check)             | Validate bolt.yaml                           |
| [`bolt migrate`](/cli/migrate)         | Convert v2.0 bolt.yaml/bolt.local.yaml       |
| [`bolt config`](/cli/config)           | Manage configuration                         |
| [`bolt plugin`](/cli/plugin)           | Manage plugins                               |
| [`bolt inspect`](/cli/inspect)         | Preview resolved steps for a task or flow    |
| [`bolt version`](/cli/version)         | Print version                                |
| [`bolt self-update`](/cli/self-update) | Update to latest release                     |
| `bolt ai`                              | Generate `.bolt/ai-context.md` for AI agents |

## Global Options

These options work with all commands:

| Flag        | Description             |
| ----------- | ----------------------- |
| `--help`    | Show help for a command |
| `--version` | Print Bolt version      |

## Common Patterns

### Run tasks in the typed order

```bash
# Run tasks in the exact order you type — no hidden reordering
bolt run update build start

# Pure preview: no commands, plugins, hooks, or file writes
bolt run update build --dry-run
```

### Run a flow

```bash
# Run a predefined, ordered goal
bolt run daily
```

### Pass parameters

```bash
# Params apply to the whole run and override with: values
bolt run build --target=client
bolt run build --config=debug
```

## Invalid flags

Every command rejects unknown flags and undeclared reserved names with exit code `2`
before anything runs. The error lists that command's supported flags and hints
`bolt <cmd> --help`. Did-you-mean suggestions use only that command's own flags.
Reserved names (`json`, `agent`, `execute`, `plan`, `confirmed-by-user`, and the
unimplemented forms of `dry-run` / `simulate` on commands that do not declare them)
fail with `--<name> is reserved by bolt and not supported yet`. Exceptions that are
declared on purpose: `bolt version --json`, `bolt migrate --dry-run`,
`bolt run --dry-run` / `--simulate`.

Only `bolt run` and `bolt inspect` accept `--key=value` task params and a `--`
passthrough. Other commands reject arguments after `--` (with a "Bolt flags go before
`--`" hint when the token looks like a flag).

## Exit Codes

| Code | Meaning |
| ---- | ------- |
| 0 | Success |
| 1 | Task failure while running |
| 2 | Usage error (unknown flag/command/task, reserved flag) |
| 3 | Config error (`bolt.yaml` missing/invalid, or `--dry-run` config problems) |

## Configuration Discovery

Bolt searches for `bolt.yaml` by walking up the directory tree from the current
working directory. The first file found is used. Optional `vars` overrides are
read from `bolt.local.yaml` next to it.

```
/current/working/dir/bolt.yaml     # Found first, used
/current/working/bolt.yaml         # Not checked
/current/bolt.yaml                 # Not checked
```
