---
title: "bolt env"
description: "Probe declared environment checks. Does not install tools."
---

`bolt env probe` compares the checks declared for this project with what the plugins report on this machine.

## Usage

```bash
bolt env probe [--json] [--manifest <path>]
```

## Description

The command is read-only. It does not install tools, and it does not run `ue/setup`.

Checks come from `env.checks` in `bolt.yaml`, from the file named by `env.manifest`, or from `--manifest`. A path is relative to the directory that contains `bolt.yaml`. `--manifest` replaces the `env` block for that invocation.

Plugins register handlers with capability `env.check` and a stable `checkId`. Probe calls the handler whose id matches. The handler receives the declaration on `ctx.envCheck`.

`data.checks` lists every result (`pass`, `fail`, `warn`, `skip`). `data.gaps` lists fail and warn rows with `id`, `current`, `expected`, and `fix`. A gap is still exit 0. `require: false` turns a failing check into `warn`, which stays in `gaps`.

Human output prints one line per check and `Fix:` for fail and warn rows. `--json` prints one `bolt.env.probe/v1` document and nothing else on stdout.

## Options

| Flag                | Description                                                              |
| ------------------- | ------------------------------------------------------------------------ |
| `--json`            | Print one `bolt.env.probe/v1` document. `ok` is true when the exit is 0. |
| `--manifest <path>` | Read checks from this file instead of `bolt.yaml` `env`.                 |

## Exit codes

| Code | Description                                                                                        |
| ---- | -------------------------------------------------------------------------------------------------- |
| 0    | The probe finished. Gaps may be non-empty. No declared checks is a warning, `ENV_NO_MANIFEST`.     |
| 1    | A check handler threw (`RUN_FAILED`).                                                              |
| 2    | Unknown flag or other usage error.                                                                 |
| 3    | `MANIFEST_INVALID` (illegal `env`, drive letter, or path escape) or `CHECK_UNKNOWN` (no provider). |

## Examples

```bash
bolt env probe
bolt env probe --json
bolt env probe --manifest env.manifest.yaml --json
```

```yaml
env:
  checks:
    - id: fixture.tool.a
      require: true
    - id: fixture.tool.b
      require: true
```
