List tasks, flows, and workspace roots defined in `bolt.yaml`.

## Usage

```bash
bolt list
```

## Description

Lists every **task** (`bolt run <task...>`) and every **flow** (`bolt run <flow>`)
defined in your project. Each flow also shows its ordered steps and description, so
you can see at a glance what a flow will run. When `bolt.yaml` has a `workspace`
block, the command also lists those roots (`id`, `role`, `path`, optional `vcs`).
A path that is not on disk is still listed, with `path does not exist`. `--json`
adds `data.workspace.roots` and sets `exists`. The command does not update those
paths.

## Options

| Flag     | Description                                                                                           |
| -------- | ----------------------------------------------------------------------------------------------------- |
| `--json` | Print one `bolt.list/v1` JSON document on stdout. Logs go to stderr. `ok` is true when the exit is 0. |

## Examples

```bash
bolt list
```

Output example:

```
bolt.yaml: /path/to/bolt.yaml

TASKS (bolt run <task...>)

  kill
  update
  genproj
  build
  start

FLOWS (bolt run <flow>)

  daily  update → build → start
    Update, build, and launch the editor
  reset  kill → update → genproj → build
    Kill, update, regenerate, rebuild
```
