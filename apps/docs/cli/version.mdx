Print the current Bolt version.

## Usage

```bash
bolt version
```

## Description

Prints the installed version of Bolt. Use this to verify your installation or when reporting issues.

## Options

| Option   | Description                                                                 |
| -------- | --------------------------------------------------------------------------- |
| `--json` | Print the version, supported plugin API versions, and capabilities as JSON. |

## Examples

```bash
bolt version
bolt --version
```

Both print the version compiled into that binary, for example `2.1.1`.

```bash
bolt version --json
```

```json
{
  "version": "2.1.1",
  "plugin_api": [1, 2],
  "manifest_format": 2,
  "capabilities": [
    "handler-results",
    "capability-tags",
    "plugin-api-2",
    "plugin-manifest",
    "agent",
    "execute"
  ]
}
```

`plugin_api` lists every plugin API version this bolt accepts. `capabilities` is append-only. Plugin authors check for `plugin-api-2` before declaring `apiVersion: 2`. `plugin-manifest` means this bolt writes content-addressed plugin manifests (`bolt plugin build`, and a human `bolt run`). `agent` and `execute` mean `bolt run` can preview and execute an `ai: true` plan (`--agent` / `--execute --plan=<hash>`). They do not mean confirm-tier handlers have been signed off. An older bolt prints only the version string instead of JSON; treat it as plugin API v1 only.
